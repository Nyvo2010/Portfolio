# Writings

Each YAML file contains:

```yaml
title: "Post title"
date: "2026-09-08"
imageSource: "/assets/writings/your-cover.png"
body: |-
  Markdown body
```

Images live in `public/assets/writings/` (mirrors
`public/assets/projects/`), with optional 480w WebP thumbs in
`public/assets/writings/thumbs/`.
