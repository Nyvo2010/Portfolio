# Writings

Each YAML file contains:

```yaml
title: "Post title"
date: "2026-09-08"
body: |-
  Markdown body
```

No cover images or thumbs — writings are text-only, except for
images embedded mid-text in the Markdown body
(`![alt](/assets/writings/your-image.png)`). Those live in
`public/assets/writings/`.
